# New API 功能面试速记

## 一、New API 是什么

New API 是一个 AI API 网关和用量管理系统。它将多个上游模型服务接入同一个平台，为下游应用提供统一的 API 入口，并通过 Web 控制台集中管理渠道、模型、用户、令牌、额度和调用记录。

它的核心是 **统一模型接口 + 渠道路由 + 用户与令牌管理 + 额度计费与运营**。

## 二、主要功能

### 1. 统一模型接口

- **统一 API 入口**：通过 OpenAI 兼容接口接入多个模型供应商和兼容服务，也支持部分供应商对应的接口格式。
- **接口适配**：根据渠道类型处理请求转发、协议适配和响应返回。
- **多模态能力**：支持文本、Embedding、图像、音频等接口，部分版本和渠道还支持其他模型能力；实际能力取决于接口、渠道及上游服务。

### 2. 渠道与模型管理

- **渠道管理**：配置上游供应商类型、API Key、服务地址及可用模型等信息。
- **模型管理**：管理模型名称、可用状态、渠道关联和定价倍率等配置。
- **模型映射**：将客户端请求的模型名称映射到上游实际使用的模型。
- **渠道测试与多 Key 管理**：测试渠道可用性，并管理渠道的上游凭证。

**渠道**是连接上游服务的一组配置；**模型**是客户端请求的能力或标识；**分组**用于组织用户、令牌和可用渠道，关联权限、路由与倍率。

### 3. 路由分流与容错

- **渠道筛选**：根据请求模型、用户或令牌分组、渠道状态等条件确定候选渠道。
- **优先级与权重**：通过渠道优先级和加权随机选择上游，实现主备和流量分配。
- **失败处理**：根据配置对失败请求进行重试或切换渠道。
- **渠道状态管理**：通过测试和状态配置管理渠道的可用性。

### 4. 用户、令牌与权限

- **用户和角色管理**：管理用户账号、分组及不同角色的操作权限。
- **API 令牌**：为客户端创建调用凭证，令牌可关联用户和分组。
- **调用限制**：可按令牌配置额度、有效期、模型范围、IP 白名单等限制，具体取决于版本和配置。
- **账号安全**：提供账号认证及相关安全管理能力。

### 5. 额度与计费

- **额度管理**：管理用户或令牌的可用额度，并根据调用消耗进行扣减。
- **模型与分组倍率**：通过模型、分组等计费配置计算消耗。
- **支付与兑换**：提供充值、兑换码及订阅等相关功能，具体取决于版本和部署配置。
- **用量和费用统计**：按调用记录统计模型使用量与消耗，支持查看和核算。

### 6. 日志、看板与控制台

- **调用日志**：记录模型、渠道、状态、Token、耗时和额度消耗等信息。
- **数据看板**：展示请求量、模型使用、用户、性能和消耗等统计信息。
- **Web 控制台**：提供渠道、模型、用户、令牌、额度及系统配置的管理界面。
- **游乐场**：在控制台中调用和试用模型。
- **管理 API**：通过接口管理用户、渠道、模型、令牌、日志等平台资源。

## 三、整体关系

```text
业务应用 / AI 客户端
          |
          | New API 令牌 + 模型请求
          v
       New API
  |       |        |        |
权限校验 渠道路由 额度计费 日志统计
          |
          v
  上游模型渠道 / 供应商
```

New API 位于客户端和上游模型服务之间：对客户端提供统一入口，对上游管理渠道，同时对调用过程进行授权、计量和记录。

## 四、面试复述

> New API 是一个 AI API 网关和用量管理平台。它把多个模型供应商接入到统一平台，对客户端提供兼容 API，并通过渠道和模型映射管理上游。请求进入后，平台根据模型、分组、渠道优先级和权重选择上游，还可以进行重试和渠道切换。它同时提供用户、角色和 API 令牌管理，以及额度、计费、日志、数据看板和 Web 控制台，方便集中管理模型调用和使用成本。
