# AI Prompting for Everyone：成为 AI Power User

## 1. 课程与学习目标

- **课程来源**：吴恩达（Andrew Ng）/ DeepLearning.AI《AI Prompting for Everyone》（按学习者提供的信息记录）。
- **学习目标**：成为 **AI power user（AI 高效使用者）**，把 AI 用于日常学习和工作，提高任务完成的效率与质量。
- **学习主线**：PAR。具体英文展开、定义和课程示例，待补充课程原文或截图后整理。

## 2. 学习记录方式

每次学习按以下顺序补充：

1. **核心概念**：课程讲了什么，解决什么问题？
2. **课程示例**：记录任务、提示词和 AI 的回答。
3. **自己的实践**：把方法用到一个实际任务中。
4. **结果与改进**：哪些输出可用，哪些需要核实或重新提示？

## 3. 提示词练习模板（补充实践）

提示词可以围绕**目标、上下文、约束和输出格式**组织；需要时补充示例。

```text
我的目标是：[希望完成的具体任务]
背景与材料：[相关信息、已有资料、面向的读者]
要求与约束：[范围、篇幅、语气、必须保留的信息]
输出格式：[列表、表格、步骤或其他形式]
参考示例：[可选，给出期望的输出样式]

请基于提供的材料完成任务；材料不足的地方请明确指出。
```

## 4. 实践与复盘（补充实践）

**明确任务 → 提交提示词 → 检查结果 → 给出具体反馈 → 再次检查 → 保存有效模板。**

检查时重点关注：是否完成目标、事实是否有依据、是否遵守约束、输出是否便于直接使用。遇到失败案例，记录具体问题，例如“遗漏限制条件”“编造材料中没有的数据”，再针对问题调整提示词。
