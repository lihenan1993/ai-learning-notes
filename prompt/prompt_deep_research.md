# 深度研究：Web Search 与 Deep Research

## 1. 什么是深度研究

**深度研究适合需要调查多个子问题、交叉引用多方证据，并综合分析后才能回答的问题。** 它通常需要拆解任务、多轮检索、阅读资料、比较不同观点及证据，再形成带引用的结论。

这里的“深入思考”是指对证据进行分析、比较和推断，包括解释分歧、识别研究局限、区分相关性与因果性，而不只是增加回答篇幅或链接数量。

课程图片使用的名称是 **Deep Research（深度研究）**。用户提到的“deep search”在本笔记中按这一含义整理；不同产品的名称和具体功能可能不同。

## 2. 课程图示：什么时候使用哪一种方式

以下表格翻译自《AI Prompting for Everyone》课程截图，不附原图。

| 对比维度 | Web Search（网页搜索） | Deep Research（深度研究） |
| --- | --- | --- |
| 示例一 | 帮我找一家附近评价很高的健身房。 | 每日步数对长期健康有什么影响？ |
| 示例二 | 迪拜这周天气怎么样？ | 天气如何影响迪拜的旅游业？ |
| 需要回答的问题 | 单个问题 | 多个问题或子问题 |
| 人工回答所需时间 | 秒级 | 几分钟到几小时 |
| 信息来源数量 | 少量来源 | 数十到数百个来源 |
| 触发方式 | 系统自动触发，或由用户主动要求 | 通常由用户主动发起 |

**表中的时间指人类回答问题所需的时间，不是 AI 的运行时间。** 来源数量与触发方式是课程中的经验性描述，不是所有产品都遵守的固定规则，也不意味着必须收集足够多的链接才能算深度研究。

## 3. 作者的经验框架

按课程图示，可以从以下四个维度判断任务规模：

1. **问题数量**：是在查一个具体事实，还是必须拆成多个子问题才能回答？
2. **人工耗时**：人类查到资料后能迅速回答，还是需要花几分钟到几小时调查、比较与分析？
3. **来源规模**：少量资料是否足够，还是需要覆盖多种研究、数据与观点？
4. **触发方式**：简单检索可能由系统自动完成；复杂研究通常需要用户明确发起并交代范围。

**简化选择：查具体事实，先用 Web Search；做多问题、多来源的综合调查，考虑 Deep Research。** 其中前三项帮助判断工作量，触发方式则提醒用户如何启动相应功能。

例如，“迪拜这周天气怎么样”主要需要天气预报；“天气如何影响迪拜旅游业”则可能需要同时调查气候季节性、游客数量、酒店入住率、户外活动和旅游旺淡季，并判断这些因素之间的关系。后者更适合深度研究。

## 4. 深度研究如何形成回答（补充实践）

**明确目标与范围 → 拆分子问题 → 检索并阅读资料 → 比较证据与观点 → 对缺口继续检索 → 综合分析并附引用。**

| 步骤 | 需要完成的工作 |
| --- | --- |
| 明确范围 | 确定研究目标、时间、地区、对象和需要支持的决策 |
| 拆分问题 | 列出回答主问题必须解决的子问题，避免漫无目的地搜索 |
| 收集证据 | 优先使用相关领域的官方数据、原始研究、系统综述及专业机构资料 |
| 比较与核验 | 检查不同研究的口径、方法、样本和适用条件，识别重复转载 |
| 补充调查 | 对证据缺口、相互矛盾的结论和重要反例继续检索 |
| 形成回答 | 给出综合结论、关键依据、不同观点、局限性和可追溯的引用 |

深度研究通常也会使用网页搜索。两者的区别主要在于任务范围、调查深度和综合分析程度，而不是是否联网。多步骤流程也不必然意味着使用多个独立模型。

## 5. 多方引用不等于堆积来源（补充实践）

- **追求独立证据**：多个网站转载同一份报告，不能算多份独立研究。
- **让引用支持具体结论**：说明哪份资料支持哪个判断，而不只是附上链接清单。
- **按证据质量比较观点**：不能因为两种观点都存在，就默认它们同样可信。
- **核对原文与限制**：确认结论适用的时间、地区和人群，注明仅能访问摘要或部分正文的情况。
- **保留不确定性**：搜索更多资料也不保证一定有答案；证据不足时应明确说明。

指定来源的方法可参见：[Web Search：获取最新知识](prompt_web_search.md)。

## 6. 深度研究提示词模板（补充实践）

```text
请对以下主题开展深度研究：[主题]。
研究目标：[要回答的核心问题或支持的决策]。
范围：[时间、地区、研究对象及排除项]。

请先拆分关键子问题，再进行多轮检索、阅读和交叉核验。
优先使用：[指定机构、官方数据、原始论文、系统综述等]。
覆盖主要观点、相反证据和研究局限，不以链接数量代替证据质量。

输出要求：
1. 核心结论与主要依据；
2. 各子问题的调查结果；
3. 证据对比表：来源、日期、方法或口径、发现、局限；
4. 不同观点的分歧及可能原因；
5. 尚未解决的问题和不确定性。

请为关键事实附可追溯的引用，区分来源事实与综合推断。
无法读取全文或核实的内容请明确说明，不要编造来源。
如果当前工具不支持深度研究，请说明可完成的范围。
```
